# Portfolio Intelligence

A starter scaffold for a portfolio intelligence project with modules for market data, portfolio logic, database access, and utilities.

## Structure

- config/: configuration and constants
- google/: Google Sheets integration helpers
- market/: market data, analytics, signals, ranking, and models
- portfolio/: holdings and allocation helpers
- database/: database access helpers
- utils/: logging and general helpers

## Run

```bash
python main.py
```
